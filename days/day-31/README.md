# Task: Deploying and Managing a Web Application

The Nautilus DevOps team is tasked with deploying a Python-based web application on Azure. You need to create a web app using the following specifications

## Task Details

1. The Web App name should be `nautilus-webapp`.
1. It should be created in the `central US` region under the default resource group.
1. The publish option should be set to `Code`.
1. The Runtime Stack should be Python with Linux as the operating system.
1. Create a new App Service Plan named `nautilus-learn-python` with the SKU `Basic B1`.
1. Application Insights should be disabled.
1. Add tags:
    * Name: WebAppLearning
    * Environment: Dev

Make sure the web app is in Running state after creation.
