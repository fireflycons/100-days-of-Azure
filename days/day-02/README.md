# Task: Create an Azure Virtual Machine

The Nautilus DevOps team is planning to migrate a portion of their infrastructure to the Azure cloud incrementally. As part of this migration, you are tasked with creating an Azure Virtual Machine (VM).

# Task Details

1. Use the existing resource group.
1. The VM name must be `nautilus-vm`, it should be in `southcentralus` region.
1. Use the `Ubuntu 24.04 LTS image` for the VM.
1. The VM size must be `Standard_B1s`.
1. Attach a default Network Security Group (NSG) that allows inbound SSH (port 22).
1. Attach a 30 GB storage disk of type `Standard HDD`.
1. The rest of the configurations should remain as default.
